# 卷间交接契约

> 本文件在两卷中各存一份（`survey-writing/references/handoff.md` 与 `survey-ops/references/handoff.md`），内容必须一致；改一份时同步另一份。


写作卷 `survey-writing` ↔ 体系卷 `survey-ops` 的唯一交接面。两卷各自 SKILL.md 只放摘要，细则以此为准。

## 为什么要有这个文件

分卷前的接口是残缺的：写作侧只说「帮我验这条」，体系侧只回「一个编号」。
强度要求不过接口 → 体系按存在性验 → 回写作发现撑不住 → 再退回。同一批引文反复返工的根因在此。

## 接口一　写作 → 体系（补文献请求）

每一条须给全五项，缺项体系侧可拒收：

| 字段 | 内容 | 依据 |
|---|---|---|
| 论断原文 | 将被引文支撑的那句话，逐字抄录 | 不许只写「第 3 节需要一篇关于 X 的」 |
| 强度要求 | 弱／中／强／最高（§2 四级） | 决定体系侧要找到什么等级的证据 |
| 需要的证据类型 | 直接文献／综述／数据／机理文献 | 强论断须覆盖比较双方 |
| 现用占位 | 正文占位符或待补位置 | 便于回填 |
| 时效 | 何时要用 | — |

**不许**把「帮我找几篇相关的」当请求——那是没想清论断，写作侧先自己把论断写成一句能站住的话。

## 接口二　体系 → 写作（验证回执）

每一条须回传四项：

| 字段 | 内容 | 依据 |
|---|---|---|
| 编号 | 台账号＋正文号（双轨，§8.5） | 两边各自编号，禁重编 |
| 证据等级 | A＝已对照本地原文／B＝仅凭摘要／C＝仅凭书目元数据 | §4.2 |
| 权威记录出处 | Crossref／arXiv／出版方页面的具体记录 | 供写作侧复核 |
| **限定词** | 材料体系、工况范围、相关性与因果的边界 | **不许丢**——写作侧转述时照搬，不得外推（§2 高危形态） |

C 级不得单独支撑强论断；体系侧须在回执里显式标注，不得只给编号了事。

## 接口三　体系 → 写作（台账变更）

台账条目被修正或删除时，体系侧交变更清单（条号＋改了什么＋依据），由写作卷 §9 做冲击扫描：
定位论断声明位置 → 返工清单 → 用户分诊（立即改／排队／明确不动）。

**体系侧不得自行修改正文**；写作侧不得绕过冲击扫描直接改字。

## 接口四　写作 → 体系（概念与台账同步）

正文改动涉及概念名、定义、首现位置或复用范围时，同一落文批次内更新 `docs/concepts.md`（§11.7）。
涉及引用集变动时，走 §8 台账 diff，以 diff 报告为准，不以声明为准。

## 何时必须走接口

不是每件事都要跨卷。判定表：

| 情形 | 走不走 |
|---|---|
| 只改措辞，不动引用集与概念 | 不走，写作卷内闭环 |
| 引用集有任何变动 | 走接口一 ＋ 接口二 |
| 某位置等级为 B/C 且要撑中／强论断 | 走接口一；体系卷按 §7.4 回三分类（甲／乙／丙） |
| 忠实性核对（§4.2），甲类已有全文 | **不走**，写作卷自己核完写证据行 |
| 台账条目被改或删 | 走接口三 |
| 概念名或定义变动 | 走接口四 |
| 纯查询、图表工程、投稿格式、结构重排 | **两卷都不走** |

## 混合任务的固定顺序

一句话里同时含「补文献」与「落笔」时，顺序不可倒：

1. **写作卷判强度**——先把「将被支撑的那句话」逐字写出来，定弱／中／强／最高（§2）。没这一步，体系卷无从判断要找什么等级的证据。
2. **体系卷取证**——先按 §7.4 判有无全文（甲／乙／丙），再按 §7 验著录、§8 入账顺延。乙丙类去取，取不到如实回「取不到」，不得降格充数。
3. **写作卷落笔**——按接口二拿回编号、等级、限定词，转述时不得外推。

**禁止跳到第 2 步**（论断还没写成就去找文献）；**禁止跳过第 3 步的限定词**（拿到编号就直接写）。这两条是同一批引文反复返工的根因。

## 两条演进通道

| 通道 | 源 | 落点 | 机制 |
|---|---|---|---|
| 写作 | 进度板的行文案例表 | `survey-writing` §14 | 锚点＋行数＋末行指纹 |
| 体系 | 进度板的工程条目＋事故回执 | `survey-ops` §15 | 日期游标 |

**转运规则**：写作通道判为「非行文·机械类」的案例，写入演进日志的「转运待评估」；体系通道判为「非体系·学术类」的条目，转运回案例表。**两卷都不许把转运物直接丢掉**。
