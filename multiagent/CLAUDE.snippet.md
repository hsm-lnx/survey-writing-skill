# 项目红线（多智能体模式依赖）

把下面这段并入你项目的 `CLAUDE.md` 顶部。已有 `CLAUDE.md` 的，**只追加，不覆盖**。
没有 `CLAUDE.md` 的，把本文件复制为 `CLAUDE.md` 再按项目改写。

1. **章节编号以正文为准。** 大纲与台账的编号只作参照，冲突时以正文实际编号为准。
2. **`bib/verified.md` 是唯一文献台账。** 只增不改、编号顺延；新增前先对全台账做 DOI 精确去重与题名模糊匹配，命中即按既有号处理。
3. **先读对应卷再动手。** 写作判断读 `skills/survey-writing/SKILL.md`，机械运转读 `skills/survey-ops/SKILL.md`；判不准时按判据分：读起来站不站得住 → 写作卷，对账对不对得上 → 体系卷。
4. **进度板只经约定的通道追加。** `docs/progress.md` 禁止手改条目或整文件重写；追加位置由项目约定（有 `scripts/progress_append.py` 就用它）。
5. **概念变动同批同步。** 正文概念新增、改名、精化、删除，须在同一落文批次内更新 `docs/concepts.md`；未同步视为该批未完成。
6. **对话即记录。** 用户每提一个行文问题，无论是否落文，都按项目约定记进进度板；不指定则由法官在收工时记。
7. **改前备份、冻结区不动、判不准就停。** 改任何已存在文件前先备份到 `reports/_raw/`；冻结范围以 `docs/freeze_register.md` 为准（没有该文件时，由用户当轮口头指定并写进裁决表）；归不准、判不准、对不上账时先不改，报用户。
