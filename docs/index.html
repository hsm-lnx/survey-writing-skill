survey-writing / survey-ops
中文综述写作助手

你给它一个模糊的题目，它按固定流程把这件事做完：收敛范围 → 建核验文献库 → 搭章节骨架 → 逐段写 → 逐条核 → 交付可查的稿子。

Claude Code skills for Chinese literature reviews. No fabricated references — anything unverifiable is marked [待验证], not invented.

它解决什么问题

文献能不能查证

逐条过 Crossref / arXiv 核验，查不到就标待验证，查询记录落盘，绝不编造 DOI。

引文撑不撑得住

按引用位置分 A/B/C 等级，只有摘要的 B 级不能撑中／强论断。

写完对不对得上

正文编号与文献台账双轨，覆盖报告、忠实性校验、结构体检逐项落盘。

五分钟上手

git clone https://github.com/hsm-lnx/survey-writing-skill.git
cd survey-writing-skill
# Windows
powershell -ExecutionPolicy Bypass -File install.ps1 -ProjectRoot D:\my_survey -AutoInstall
# macOS / Linux
bash install.sh ~/my_survey --auto-install

然后进入项目目录打开 Claude Code，直接用中文说你要做什么。
